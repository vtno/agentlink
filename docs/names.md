# Names

`owner` is the pid that receives inbound ACP. It is not a supervisor. Do not call that field `parent`.

A module that belongs to one side is prefixed `Client` or `Agent`. The app connection is `AgentLink.ClientSocket`. The agent connection is `AgentLink.AgentSocket`. `AgentLink.Relay.Agent` starts the uplink and opens an `AgentLink.Agent`. `AgentLink.Uplink` dials that socket. `AgentLink.Client` is one app on the plane. `AgentLink.AgentSlot` is the slot for one connected agent. `AgentLink.Agent.Launch` is the raw command and args from the link file. It is not a process. `AgentLink.Agent.Process` opens an `AgentLink.Agent.Launch` from the caller. It is not a GenServer. The relay calls `open/5`. The handle is the port. `open/4` takes a finder and is not the behaviour callback. `open/5` takes that finder and a listener pid. `AgentLink.Agent.Reaper` keeps the pid and start time of an agent `close/1` could not stop. The pairs are a file named for this VM's OS pid and start time. `init/1` reloads that file and drops a pid whose start time no longer matches. Another VM's file is removed only when that VM is confirmed gone. A stored start time of `0`, or a start time that cannot be read, is left in place. Load, modify, and save of this VM's file take `:global.trans/3` on `{{:agentlink_reaper, vm}, self()}` for this node, so a `retain/1` during `init/1` keeps its pairs. It starts before `AgentLink.Relay.Agent`. The next relay asks it to signal those processes before `open/5`. `retain/1` writes the pairs even when that process is not running, and the call returns `{:error, :noproc}`. `reap/0` returns `{:error, :noproc}` when that process is not running.
