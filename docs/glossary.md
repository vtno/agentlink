# Glossary

Plane. Accepts sockets and applies the access policy.

Socket. One WebSocket on the plane. `AgentLink.ClientSocket` is the app connection. `AgentLink.AgentSocket` is the agent connection. The uplink dials `AgentLink.AgentSocket`.

Relay. Copies JSON-RPC between a local stdio and a plane socket. `AgentLink.Relay.Agent` opens an agent and starts an uplink. `AgentLink.Relay.Client` is not built yet.

Target. `AgentLink.Relay.Target.select/2` selects one online agent. The caller passes `wanted`, a binary or `nil`, and `online`, a list of binaries. A repeated name counts once, and the first occurrence keeps its place. An empty string is a name. `select/2` keeps the bytes as given. When `wanted` occurs in `online`, `select/2` returns that name. When `wanted` is `nil` and one name remains, `select/2` returns that name. When no name remains, the error says that no agent is online, including when `wanted` is set. When `wanted` is `nil` and more than one name remains, the error lists those names in that order and tells the operator to pass `--target`. When `wanted` is not one of the online names, the error names `wanted`, lists the online names in that order, and tells the operator to pass `--target`. Each name in an error is `inspect/1` of that binary. A bad `wanted` or a bad `online` raises `ArgumentError`. `AgentLink.Relay.Target` defines no Elixir behaviour. The client relay does not call `select/2` yet.

Frame. `AgentLink.Frame` is one JSON-RPC object on the wire. Stdio is one object per line. The agent relay and the uplink put one object in each text frame. On the plane, `AgentLink.Plane.client_frame/2` and `AgentLink.Plane.agent_frame/2` split that text on newlines, decode each piece, and keep no remainder. `client_frame/2` answers a JSON-RPC batch with -32600.

Transport. `AgentLink.Transport` is the WebSocket a relay dials. `AgentLink.Transport.WebSocket` is the Mint client. The owner receives `{:from_plane, message}` for one decoded object and `{:transport_closed, code, reason}` when that socket closes. `hold/1` stops the next dial. `preface/2` is the object sent before the outbox on every dial. `AgentLink.Uplink` dials through this behaviour.

Link. The file. Name, label, program, and plane URL. Not the live connection. The uplink reads it when it starts, on each watch, and on a non-parking close of the current socket. A missing file stops the relay.

Config. `AgentLink.Config` holds the plane URL, the optional target, and the token. For each field, `load/1` uses the `:plane`, `:target`, or `:token` option when trimming that value leaves text. When the option is omitted, `nil`, or blank, it uses `AGENTLINK_PLANE`, `AGENTLINK_TARGET`, or `AGENTLINK_TOKEN` from `:env` when trimming that value leaves text. When the variable is omitted or blank, it reads the files under `:root`. `:root` defaults to `AgentLink.Paths.root/0`. `:env` defaults to `System.get_env/0`. The config file is `AgentLink.Paths.config/0`, a JSON object with `plane` and an optional `target`. The token file is `AgentLink.Paths.token/0`. `load/1` reads the token file only when the token is still unset. That file must be a regular file in mode 0600, 0400, 0200, or 0000. A `token` key in the config file is an error, and the error names the token file. The CLI does not call `load/1` yet.

Uplink. `AgentLink.Uplink` is the process that dials. `AgentLink.Registry.Uplink` is the row recorded after that dial says hello. The first live hello for a name keeps the socket. The hello carries that relay's instance id, and "same relay" means the same id: a later hello with it releases the previous socket. A hello from another relay is rejected with close code 4001, and that relay parks until the `name` or `plane_url` in the link file changes, then it dials again. When the holder disconnects, the name is free. The plane accepts an instance id of at most 128 bytes. A longer id is rejected with close code 4002, and that relay does not redial: the id is not in the link file, so a changed `name` or `plane_url` would dial with the same id.

Agent. The stdio behaviour. `AgentLink.OpenCode` implements it and runs the binary. The relay opens the behaviour. The relay does not spawn the binary.

Client. One app already connected to the plane. Not `AgentLink.Relay.Client`, and not `AgentLink.ClientSocket`. Its capabilities are the `clientCapabilities` from that app's own `initialize`.

Slot. The plane's session state for one connected agent. Prompt queue, the in-flight turn, and the cached `initialize`. The cache is the agent's reply, not the client's capabilities.

History. `AgentLink.Plane.History` is the replay buffer for one session. It keeps the newest whole turns that fit a turn limit and a byte limit. The newest turn stays even when that turn alone is larger than `:max_bytes`. A `user_message_chunk` starts a turn. Updates before the first one are one turn. The session process calls it when the plane broadcasts a live update. An update that is not a map is not appended.

Subscription. `AgentLink.Plane.Subscription` is one process for a session a client has open. It implements `AgentLink.Plane.Subscribe`. `notify/2` sends `{:send, json}` to the client pid. `json` is `AgentLink.Frame.encode/1`. When the client dies, `:owner` receives `{:subscription_down, client_id, session_id}` and the process exits with `:normal`. `stop/1` also exits with `:normal`. The session directory starts one when a client opens, loads, or resumes a session.

Session. `AgentLink.Plane.Session` is one shared session process. It holds an `AgentLink.Plane.History` and the subscription pids. `subscribe/2` returns the capped replay as full `session/update` messages, oldest first. `replay/1` returns that list and does not start a subscription. `broadcast/2` appends one inner update, then calls `notify/2` on each subscription. The session does not store client ids or client capabilities. The session directory starts it from `open/5`.

Sessions. `AgentLink.Plane.Sessions` is the directory of those sessions. `open/5` starts a session and subscribes the client. `load/4` subscribes and returns the replay, or `{:error, :unknown}`. `resume/4` subscribes and returns `:ok`, or `{:error, :unknown}`. `leave/3` drops one client from one session. `disconnect/1` drops that client from every session. Both remove the directory entry when the subscription has already exited. `list/2` filters on `:cwd` and pages with an opaque `:cursor`. A cursor that does not decode is `{:error, :invalid_cursor}`. The directory maps each client id to its subscription pids. `AgentLink.Plane.Supervisor` starts the directory. The plane calls it for `session/new`, `session/list`, `session/load`, `session/resume`, `session/close`, a live `session/update` with a binary `sessionId` and a map `update`, and a client disconnect. A `session/update` with a binary `sessionId` whose `update` is not a map is dropped. The plane logs a warning and does not store that update. A `session/update` with no `sessionId` goes to every client on that runtime.

Agent socket protocol. `AgentLink.AgentSocketProtocol` defines the handshake's permanent-rejection close codes shared by the plane's agent socket and the relay's uplink: 4001 name taken, 4002 instance too long (maximum 128 bytes), 4003 bad name, 4004 not allowed. It does not cover the client socket. Each rejection parks the uplink with a logged reason. Restart retries any rejection; changing the link name or plane URL retries all except 4002. Other closes and transient failures retry after 500ms.
