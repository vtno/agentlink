# Glossary

Plane. Accepts sockets and applies the access policy.

Socket. One WebSocket on the plane. `AgentLink.ClientSocket` is the app connection. `AgentLink.AgentSocket` is the agent connection. The uplink dials `AgentLink.AgentSocket`.

Relay. Copies JSON-RPC between a local stdio and a plane socket. `AgentLink.Relay.Agent` opens an agent and starts an uplink. `AgentLink.Relay.Client` opens editor stdio and dials the plane. `start_link/1` requires `:plane`. `:token` and `:target` are optional. `:transport` defaults to `AgentLink.Transport.WebSocket`. `:stdio` defaults to `AgentLink.Stdio.Console`. The dial uses `default_path` `/acp` and a bearer header from `:token`. Omitted, nil, or `""` sends no header. It does not call `AgentLink.Auth.headers/0`. It sends `runtime/list` with id `"agentlink:runtime/list"`, calls `AgentLink.Relay.Target.select/2` with those runtime names in that order, then sends `runtime/select` with id `"agentlink:runtime/select"`. Those two responses are not written to the editor. Editor messages that arrive before `runtime/select` answers are copied after it, in order. A bad target, a runtime error, or a `runtime/list` result that is not a list of objects with a binary `name` stops the process with `{:shutdown, message}`. `child_spec/1` uses `restart: :transient`, so a supervisor does not restart that stop. A closed plane socket during either runtime request sends that request again. After `runtime/select` succeeds, a closed plane socket calls `hold/1` and stops the process with `{:shutdown, "plane closed"}`. ACP messages are copied unchanged, except an `initialize` result. That result sets `agentCapabilities.loadSession` to true and gives `sessionCapabilities` the keys `list`, `resume`, and `close`. A value that is already a map stays. The agent's other capabilities stay. A result that is not a map is copied unchanged. `session/list`, `session/load`, `session/resume`, and `session/close` are copied through. `agentlink connect` starts this process and does not start the plane, the agent relay, or a link-file check. A missing plane URL exits with status 1. A missing token exits with status 1. `{:shutdown, "stdio closed"}` exits with status 0, including when stdin is already closed as the client relay starts. Any other `{:shutdown, message}` exits with status 1.

Target. `AgentLink.Relay.Target.select/2` selects one online agent. The caller passes `wanted`, a binary or `nil`, and `online`, a list of binaries. A repeated name counts once, and the first occurrence keeps its place. An empty string is a name. `select/2` keeps the bytes as given. When `wanted` occurs in `online`, `select/2` returns that name. When `wanted` is `nil` and one name remains, `select/2` returns that name. When no name remains, the error says that no agent is online, including when `wanted` is set. When `wanted` is `nil` and more than one name remains, the error lists those names in that order and tells the operator to pass `--target`. When `wanted` is not one of the online names, the error names `wanted`, lists the online names in that order, and tells the operator to pass `--target`. Each name in an error is `inspect/1` of that binary. A bad `wanted` or a bad `online` raises `ArgumentError`. `AgentLink.Relay.Target` defines no Elixir behaviour. `AgentLink.Relay.Client` calls `select/2` with the names from `runtime/list`, in that order.

Stdio. `AgentLink.Stdio` is stdin and stdout for the editor. `open/1` runs in the owner and returns `{:ok, term}` or `{:error, term}`. `write/2` returns `:ok` or `:closed`. `close/1` returns `:ok`. `AgentLink.Stdio.Console` is the production behaviour. It opens file descriptors 0 and 1. Chunks arrive as `{term, {:data, binary}}`. Stdin ending arrives as `{term, :eof}`. `AgentLink.Relay.Client` is the caller. Tests pass a fake.

Frame. `AgentLink.Frame` is one JSON-RPC object on the wire. Stdio is one object per line. The agent relay and the uplink put one object in each text frame. On the plane, `AgentLink.Plane.client_frame/2` and `AgentLink.Plane.agent_frame/2` split that text on newlines, decode each piece, and keep no remainder. `client_frame/2` answers a JSON-RPC batch with -32600.

Transport. `AgentLink.Transport` is the WebSocket a relay dials. `AgentLink.Transport.WebSocket` is the Mint client. The owner receives `{:from_plane, message}` for one decoded object and `{:transport_closed, code, reason}` when that socket closes. `hold/1` stops the next dial. `preface/2` is the object sent before the outbox on every dial. `AgentLink.Uplink` and `AgentLink.Relay.Client` dial through this behaviour.

Link. The file. Name, label, program, and plane URL. Not the live connection. `AgentLink.Relay.Agent` passes the link from `AgentLink.Agent.Launch.load/1` into `AgentLink.Uplink` as `:link`. That `init/1` does not read the file. When `:link` is omitted, `init/1` calls `AgentLink.Link.read/1`. A watch and a non-parking close call `AgentLink.Link.read/1`. A missing file stops the relay. `command` and `args` in that file are not fields of `AgentLink.Link`. `program` is metadata. When `program` is missing, the value is `opencode`. `program` does not choose the command.

Launch. `AgentLink.Agent.Launch` holds the raw `command` and `args` from the link file. `load/1` takes a path or nil. Nil uses `AgentLink.Link.path/0`. `load/1` reads the file once per call. The next call reads the path again. `load/1` builds the `AgentLink.Link` from the decoded object and reads `command` and `args` from that same object. An `env` key is an error. The error does not include the value. Any value is rejected, including null. `load/1` checks `env` before `command` and `args`. `command` is required and must be a string. `load/1` trims it and stores the trimmed string. A blank command is an error. A command is absolute when it starts with `/`. A command is absolute when it starts with `\\`. A command is absolute when it starts with a drive letter, a colon, and a slash. That slash may be `/` or `\`. A single leading `\` is relative. `\opencode`, `\Users\me\kimi.exe`, and `\` are relative. These absolute forms cover Linux, macOS, and Windows. A bare name contains neither `/` nor `\`. `C:opencode` is not a bare name. `.` and `..` are not bare names. `./opencode`, `bin/kimi`, `.\opencode`, and `bin\kimi` are relative. `load/1` keeps an absolute path or a bare name. It does not search `PATH` and it does not require the path to name a file that exists. `args` is required. It must be a list of strings. `[]` is allowed. Each string is kept as written. Any other unknown key is ignored. `name`, `label`, `program`, and `plane_url` keep the defaults from `AgentLink.Link.read/1`. `load/1` does not start a process. `AgentLink.Relay.Agent` calls `load/1` once in each `init/1`. The next `init/1` reads the path again.

Process. `AgentLink.Agent.Process.open/3` opens an `AgentLink.Agent.Launch` from the caller. The caller must be `owner`. The functions run in the caller. The module does not start a GenServer. `open/3` is the `AgentLink.Agent` callback. The relay calls `open/5` for this module. The handle is the port. `open/3` does not call `AgentLink.Agent.Launch.load/1` and does not read application config. `open/4` takes a finder and is not a callback. `open/5` takes that finder and a listener pid and is not a callback. The relay passes `:agent_open_listener` to `open/5`. The default finder is `&System.find_executable/1`. A bare name uses that finder. A path that is absolute on this host is used unchanged. `open/3` does not expand that path against `cwd` or the VM cwd. `open/3` does not call the finder for that path. On Unix, a host-absolute path starts with `/`. On Windows, `:os.type/0` returns `{:win32, _}`, and a host-absolute path starts with two slashes, or with a drive letter, a colon, and a slash. Each of those two slashes may be `/` or `\`. The slash after the colon may be `/` or `\`. On Windows, a single leading slash is not absolute. `AgentLink.Agent.Launch` accepts a POSIX path, a UNC path, and a drive path on every host. `open/3` accepts only a path that is absolute on this host. Any other command is an error. `open/3` does not call the finder for that command and does not call `File.stat/1` on it. `File.stat/1` must report a regular file. `File.stat/1` follows symlinks. The Unix execute bit is not checked. `Port.open/2` is called with `{:spawn_executable, path}` and the options `:binary`, `:exit_status`, `:use_stdio`, `{:args, args}`, and `{:cd, cwd}`. `:env` is the VM environment without `AGENTLINK_WINDOWS_START`. Other variables set with `System.put_env/2` are passed. `:stderr_to_stdout` is omitted, so stderr is not merged into `{port, {:data, binary}}`. `write/2` returns `:ok` when `Port.info/1` shows an open port and `:closed` otherwise. `close/1` stops the child, or leaves the remaining pids with `AgentLink.Agent.Reaper`.

See [Agent process](agent.md#agent-process).

Config. `AgentLink.Config` holds the plane URL, the optional target, and the token. For each field, `load/1` uses the `:plane`, `:target`, or `:token` option when trimming that value leaves text. When the option is omitted, `nil`, or blank, it uses `AGENTLINK_PLANE`, `AGENTLINK_TARGET`, or `AGENTLINK_TOKEN` from `:env` when trimming that value leaves text. When the variable is omitted or blank, it reads the files under `:root`. `:root` defaults to `AgentLink.Paths.root/0`. `:env` defaults to `System.get_env/0`. The config file is `AgentLink.Paths.config/0`, a JSON object with `plane` and an optional `target`. The token file is `AgentLink.Paths.token/0`. `load/1` reads the token file only when the token is still unset. That file must be a regular file in mode 0600, 0400, 0200, or 0000. A `token` key in the config file is an error, and the error names the token file. `agentlink connect` calls `load/1` with the `--plane`, `--target`, and `--token` flags from `AgentLink.CLI`. A flag wins over the environment variable, and the environment variable wins over the file. The command exits with status 1 when the plane URL or the token is missing. `load/1` still returns a nil token when the token is unset.

Uplink. `AgentLink.Uplink` is the process that dials. `AgentLink.Registry.Uplink` is the row recorded after that dial says hello. The first live hello for a name keeps the socket. The hello carries that relay's instance id, and "same relay" means the same id: a later hello with it releases the previous socket. A hello from another relay is rejected with close code 4001, and that relay parks until the `name` or `plane_url` in the link file changes, then it dials again. When the holder disconnects, the name is free. The plane accepts an instance id of at most 128 bytes. A longer id is rejected with close code 4002, and that relay does not redial: the id is not in the link file, so a changed `name` or `plane_url` would dial with the same id.

Agent. The stdio behaviour. `open/3` takes the owner, an `AgentLink.Agent.Launch`, and the workspace. `write/2` and `close/1` stay as they are. `AgentLink.Agent.Process` implements it and runs `command` and `args`. The relay calls `AgentLink.Agent.Launch.load/1` once in each `init/1`, then calls `open/5` for `AgentLink.Agent.Process`. `program` does not choose the module.

Client. One app already connected to the plane. Not `AgentLink.Relay.Client`, and not `AgentLink.ClientSocket`. Its capabilities are the `clientCapabilities` from that app's own `initialize`.

Slot. The plane's session state for one connected agent. Prompt queue, the in-flight turn, and the cached `initialize`. The cache is the agent's reply, not the client's capabilities.

History. `AgentLink.Plane.History` is the replay buffer for one session. It keeps the newest whole turns that fit a turn limit and a byte limit. The newest turn stays even when that turn alone is larger than `:max_bytes`. A `user_message_chunk` starts a turn. Updates before the first one are one turn. The session process calls it when the plane broadcasts a live update. An update that is not a map is not appended.

Subscription. `AgentLink.Plane.Subscription` is one process for a session a client has open. It implements `AgentLink.Plane.Subscribe`. `notify/2` sends `{:send, json}` to the client pid. `json` is `AgentLink.Frame.encode/1`. When the client dies, `:owner` receives `{:subscription_down, client_id, session_id}` and the process exits with `:normal`. `stop/1` also exits with `:normal`. The session directory starts one when a client opens, loads, or resumes a session.

Session. `AgentLink.Plane.Session` is one shared session process. It holds an `AgentLink.Plane.History` and the subscription pids. `subscribe/2` returns the capped replay as full `session/update` messages, oldest first. `replay/1` returns that list and does not start a subscription. `broadcast/2` appends one inner update, then calls `notify/2` on each subscription. The session does not store client ids or client capabilities. The session directory starts it from `open/5`. This process traps exits and is linked to each subscription. A subscription crash removes that subscription. The session and its history keep running. A subscription that exits `:normal`, including when the client dies, stays a normal exit and does not stop the session.

Sessions. `AgentLink.Plane.Sessions` is the directory of those sessions. `open/5` starts a session and subscribes the client. `load/4` subscribes and returns the replay, or `{:error, :unknown}`. `resume/4` subscribes and returns `:ok`, or `{:error, :unknown}`. `leave/3` drops one client from one session. `disconnect/1` drops that client from every session. Both remove the directory entry when the subscription has already exited. `list/2` filters on `:cwd` and pages with an opaque `:cursor`. A cursor that does not decode is `{:error, :invalid_cursor}`. The directory maps each client id to its subscription pids. `AgentLink.Plane.Supervisor` starts the directory. The plane calls it for `session/new`, `session/list`, `session/load`, `session/resume`, `session/close`, a live `session/update` with a binary `sessionId` and a map `update`, and a client disconnect. A `session/update` with a binary `sessionId` whose `update` is not a map is dropped. The plane logs a warning and does not store that update. A `session/update` with no `sessionId` goes to every client on that runtime. The directory traps exits and is linked to each session. A session crash removes that session. The directory and the other sessions keep running. Their history stays in those session processes. An unexpected message to the directory still crashes the directory.

Agent socket protocol. `AgentLink.AgentSocketProtocol` defines the handshake's permanent-rejection close codes shared by the plane's agent socket and the relay's uplink: 4001 name taken, 4002 instance too long (maximum 128 bytes), 4003 bad name, 4004 not allowed. It does not cover the client socket. Each rejection parks the uplink with a logged reason. Restart retries any rejection; changing the link name or plane URL retries all except 4002. Other closes and transient failures retry after 500ms.
